# Costos estimados

Dólar de referencia: ~$925 CLP/USD.

## Costos recurrentes (sin SIMs)

Los planes de datos (SIM) van por cuenta del cliente final.

| Concepto | USD/mes | CLP/mes |
|---|---|---|
| Firebase Spark (gratis) | $0 | $0 |
| Dominio (opcional, prorrateado) | ~$1 | ~$800–1.200 |
| **Total** | | **~$0–1.200 CLP/mes** |

## Costos por SIM (a cargo del cliente)

| Proveedor | Precio |
|---|---|
| MCI Telecom (red Movistar/Telefónica) | desde $828 CLP/mes |
| M2MPro (red Entel) | desde $1.990 CLP/mes |
| Atomo | ~$10.000 CLP/mes |

Como cada nodo envía pocos MB al mes, los planes IoT baratos son suficientes.
